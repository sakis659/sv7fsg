# SV7FSG – Ραδιοερασιτεχνικός σταθμός

Η σελίδα του σταθμού SV7FSG, φιλοξενείται δωρεάν στο Cloudflare Pages.

- `index.html`: η σελίδα. Τα προσωπικά στοιχεία αλλάζουν στο `CONFIG`, στο τέλος του αρχείου.
- `news.json`: οι ειδήσεις της ενότητας «DX Νέα».
- `AGENT.md`: οδηγίες για τον agent που ετοιμάζει καθημερινά νέες ειδήσεις.
  Οι ειδήσεις δημοσιεύονται μόνο μετά από έγκριση (Merge του Pull Request).
